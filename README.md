- `ad.mp4` — the ad itself (1080×1920, 19.4 s), posted on TikTok by [@murad.spx6900](https://www.tiktok.com/@murad.spx6900)
- `VIDEO.json` — the video's address on TikTok (placeholder until it is posted)
- `CAPTION.txt` — the caption posted with it
- `main.ts` — the program the grader runs: it copies `VIDEO.json` to `/output`
